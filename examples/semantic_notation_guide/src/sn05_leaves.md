# リーフ記法

中身を持たない「行空け」「改ページ」「見出し内改行」は、`{{名前}}` / `{{名前:引数}}` の 1 行で書きます（[リーフ記法]{.term}）。`{{br}}` 以外は、**前後を空行で区切った独立の段落**として書いてください。文章の途中に書いても変換されず、そのまま文字として残ります。

## vspace … 垂直スペース

引数が数値のときは「行数」（1 行 ≒ 1.65em）、単位付きのときはその長さだけ空けます。引数を省略すると 1 行です。

| 書き方 | 空き | Typst への変換 |
|---|---|---|
| `{{vspace}}` | 1 行 | `#v(1 * 1.65em)` |
| `{{vspace:2}}` | 2 行 | `#v(2 * 1.65em)` |
| `{{vspace:.5}}` | 半行 | `#v(.5 * 1.65em)` |
| `{{vspace:15mm}}` | 15mm | `#v(15mm)` |

単位は mm / cm / pt / em / in などが使えます。

**書き方**

````markdown
ここで 1 行空けます。

{{vspace}}

ここで 3 行空けます。

{{vspace:3}}

ここで 15mm 空けます。

{{vspace:15mm}}

ここまで。
````

**表示結果**

ここで 1 行空けます。

{{vspace}}

ここで 3 行空けます。

{{vspace:3}}

ここで 15mm 空けます。

{{vspace:15mm}}

ここまで。

## pagebreak … 改ページ

その位置で改ページします。すでにページの先頭にいるときは、空のページを作りません（`#pagebreak(weak: true)`）。

**書き方**

````markdown
このページはここで終わり。

{{pagebreak}}

次のページの先頭から始まる段落。
````

**表示結果**

このページはここで終わり。

{{pagebreak}}

次のページの先頭から始まる段落。（`{{pagebreak}}` によってページが変わりました）

## vfill … 残りの高さを埋める

ページの残りの高さを空けて、後ろの内容をページの下端へ押し下げます（`#v(1fr)`）。奥付やページ下部の注記に使います。`{{pagebreak}}` と組み合わせると、そのページの使い方を固定できます。

**書き方**

````markdown
{{pagebreak}}

このページの上端にある段落です。

{{vfill}}

::: {.center}
この段落は vfill でページの下端に押し下げられています。
:::

{{pagebreak}}
````

**表示結果**（次のページ）

{{pagebreak}}

このページの上端にある段落です。

{{vfill}}

::: {.center}
この段落は vfill でページの下端に押し下げられています。
:::

{{pagebreak}}

## br … 見出し内の強制改行 {#br-heading}

長い見出しが変な位置で折り返さないように、改行位置を指定します。`{{br}}` だけは段落ではなく、**見出しの文字列の中に**埋め込んで書きます。見出し本体では改行し、目次・柱では消えます（日本語の見出しなので空白も入りません）。

**書き方**

````markdown
### 長い見出しを意図した位置で{{br}}改行する例
````

**表示結果**

### 長い見出しを意図した位置で{{br}}改行する例

目次では「長い見出しを意図した位置で改行する例」と 1 行で表示されます。

::: {.note}
`{{br}}` は本文の段落にも書けますが、主な用途は章・節タイトルです。pptx ノートの見出しや、procedure の `chapter` 操作の見出し文字列にも書けます。
:::
