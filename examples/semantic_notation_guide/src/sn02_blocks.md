# ブロック記法（fenced div）

複数行のまとまりに意味を付けるときは、`:::` で囲む [fenced div]{.term} を使います。開始行は `::: {.クラス名}`、終了行は `:::` だけです。`:::` の前後には空行を入れてください。

## note … 補足情報の囲み

本筋から外れる補足を、薄い背景で区切って見せます。

**書き方**

````markdown
::: {.note}
ここは補足説明です。読み飛ばしても本筋は追えます。
:::
````

**表示結果**

::: {.note}
ここは補足説明です。読み飛ばしても本筋は追えます。
:::

既定では枠も背景も描きません（`frame=true` を付けると枠と背景が付きます。第 3 章）。

## warning … 注意喚起の囲み

読み飛ばされると困る注意書きに使います。文字はゴシック太字になります。

**書き方**

````markdown
::: {.warning}
この操作は元に戻せません。実行前にファイルを保存してください。
:::
````

**表示結果**

::: {.warning}
この操作は元に戻せません。実行前にファイルを保存してください。
:::

## leadline … 擬似見出し・リード行

見出しにはしたくないが、独立した行で強く伝えたい一文に使います。大きめのゴシック太字になります。

**書き方**

````markdown
::: {.leadline}
結論：原稿にはセマンティック記法だけを書く。
:::
````

**表示結果**

::: {.leadline}
結論：原稿にはセマンティック記法だけを書く。
:::

## widequote … 幅広引用

引用や例文を、行間を少し広げて見せます。

**書き方**

````markdown
::: {.widequote}
「考えるとは、比べることである。」
比べる相手を持たない思考は、すぐに堂々めぐりになる。
:::
````

**表示結果**

::: {.widequote}
「考えるとは、比べることである。」
比べる相手を持たない思考は、すぐに堂々めぐりになる。
:::

## largefontblock … 大きい文字のブロック

本文より一回り大きい文字（約 1.44 倍）で見せます。属性は取りません。

**書き方**

````markdown
::: {.largefontblock}
大事なことなので、大きく書きます。
:::
````

**表示結果**

::: {.largefontblock}
大事なことなので、大きく書きます。
:::

## blockindent … 字下げブロック

ブロック全体の左側を空けます。既定は 2em で、`indent` 属性で量を変えられます（数値＋単位のみ。`3em` / `10mm` など）。

**書き方**

````markdown
::: {.blockindent}
既定の字下げ（2em）です。
:::

::: {.blockindent indent=6em}
indent=6em で深く字下げしています。
:::
````

**表示結果**

::: {.blockindent}
既定の字下げ（2em）です。
:::

::: {.blockindent indent=6em}
indent=6em で深く字下げしています。
:::

## center … 中央寄せ

ブロック内の行を中央に寄せます。両端揃えはしません。

**書き方**

````markdown
::: {.center}
中央寄せしたいテキスト

2 段落目も中央に寄ります
:::
````

**表示結果**

::: {.center}
中央寄せしたいテキスト

2 段落目も中央に寄ります
:::

## keep-together … ページ途中で分割しない

ブロックを途中で改ページさせたくないときに使います。現在のページに収まらなければ、ブロックごと次のページへ送られます。表と説明文、図と図の説明をまとめておくのに向いています。

**書き方**

````markdown
::: {.keep-together}
**手順のまとめ**

1. 原稿を書く
2. レシピに insertmd を並べる
3. crop_to_pdf でビルドする
:::
````

**表示結果**

::: {.keep-together}
**手順のまとめ**

1. 原稿を書く
2. レシピに insertmd を並べる
3. crop_to_pdf でビルドする
:::

::: {.note}
1 ページに収まらない長さのブロックは、まとめようがないのでページからはみ出します。keep-together は数行〜半ページ程度のまとまりに使ってください。旧仕様の `lines=14` 属性は現在は使われません（書いても無視されます）。
:::

## ブロックの入れ子

fenced div は入れ子にできます。外側の `:::` を長くする（`::::`）と、どこで閉じているかが読みやすくなります。

**書き方**

````markdown
:::: {.widequote frame=true colback=blue!8}
::: {.center}
背景色つきの囲みの中で、中央寄せ
:::
::::
````

**表示結果**

:::: {.widequote frame=true colback=blue!8}
::: {.center}
背景色つきの囲みの中で、中央寄せ
:::
::::

囲み（note / warning / leadline / widequote）の中は、外側に center があっても両端揃えに戻ります。囲みの中を中央寄せにしたいときは、このように囲みの**内側**に center を置きます。
