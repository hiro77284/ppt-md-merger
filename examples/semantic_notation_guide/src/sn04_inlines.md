# インライン記法{{br}}（bracketed span）

行の中の語句に意味を付けるときは、`[語句]{.クラス名}` と書く [bracketed span]{.term} を使います。`[ ]` の中は普通の Markdown なので、太字やリンクを入れることもできます。

## term … 専門用語・定義語

初めて出てくる用語や、定義している語に使います。青の太字になります。

**書き方**

````markdown
この現象を [メモリリーク]{.term} と呼びます。
````

**表示結果**

この現象を [メモリリーク]{.term} と呼びます。

## keyword … キーワード・重要語

読み手に必ず拾ってほしい語に使います。太字に淡い黄色のハイライトが付きます。

**書き方**

````markdown
設定を変えたら必ず [再起動]{.keyword} してください。
````

**表示結果**

設定を変えたら必ず [再起動]{.keyword} してください。

## path … ファイル名・パス・コマンド名

ファイル名やディレクトリ、コマンド名に使います。等幅フォントになります。

**書き方**

````markdown
設定は [examples/constants_settings.toml]{.path} に書き、
[pptmdmerge]{.path} コマンドで読み込みます。
````

**表示結果**

設定は [examples/constants_settings.toml]{.path} に書き、
[pptmdmerge]{.path} コマンドで読み込みます。

::: {.note}
バッククォートのインラインコード（`` `config.yaml` ``）も等幅になりますが、こちらは「コード」の意味で、GFM でもそのまま残ります。`.path` は「ファイル名」という意味を持たせたいときに使います（GFM ではインラインコードになります）。
:::

## kbd … キー入力

キーボードのキーや、キーの組み合わせに使います。キーキャップ風の枠が付きます。

**書き方**

````markdown
[Ctrl+C]{.kbd} で停止し、[↑]{.kbd} [Enter]{.kbd} で再実行します。
````

**表示結果**

[Ctrl+C]{.kbd} で停止し、[↑]{.kbd} [Enter]{.kbd} で再実行します。

## emph … 意味付きの強調

文脈上の強調に使います。PDF では Typst の `emph`（強調）になります。和文フォントには斜体がないため、和文ではほとんど見た目が変わりません。欧文は *italic* になります。

**書き方**

````markdown
ここで言う「完了」は [提出まで]{.emph} を含みます（[not just writing]{.emph}）。
````

**表示結果**

ここで言う「完了」は [提出まで]{.emph} を含みます（[not just writing]{.emph}）。

## rightlabel … 行末ラベルの右寄せ

行の残りを空けて、ラベルを右端に寄せます。日付や担当者名、ページ番号風の表記に使います（旧来の `\hfill` の用途）。

**書き方**

````markdown
第 1 回 打ち合わせ議事録 [2026-10-25 記録：山田]{.rightlabel}

チェック項目 A [済]{.rightlabel}

チェック項目 B（長めの項目名） [未]{.rightlabel}
````

**表示結果**

第 1 回 打ち合わせ議事録 [2026-10-25 記録：山田]{.rightlabel}

チェック項目 A [済]{.rightlabel}

チェック項目 B（長めの項目名） [未]{.rightlabel}

## 組み合わせ

インライン記法は 1 つの文の中でいくつでも使えます。

**書き方**

````markdown
この [メモリリーク]{.term} を [config.yaml]{.path} で確認し、
[Ctrl+C]{.kbd} で停止してから [必ず]{.keyword} ログを保存します。
````

**表示結果**

この [メモリリーク]{.term} を [config.yaml]{.path} で確認し、
[Ctrl+C]{.kbd} で停止してから [必ず]{.keyword} ログを保存します。

囲みの中や表のセルの中でも使えます。

::: {.warning}
[rm -rf build]{.path} を実行すると [build]{.path} ディレクトリが [完全に]{.keyword} 消えます。
:::

| 操作 | キー |
|---|---|
| コピー | [Ctrl+C]{.kbd} |
| 貼り付け | [Ctrl+V]{.kbd} |

## 注意点

- 1 つの span に複数のクラスを書いた場合（`[x]{.term .keyword}`）、効くのは**最初に書いた既知のクラス 1 つだけ**です。
- 定義にないクラス（`[x]{.foo}`）は、PDF では中身の文字だけが残ります。
- `]` の直後に空白を入れずに `{` を書いてください。`[語句] {.term}` のように空白があると span になりません。
