# はじめに

## 本書の目的

本書は、PPT & MD merger の原稿 MD に書ける[セマンティック記法]{.term}を、一つずつ「書き方」と「PDF での表示結果」を並べて解説する用例集です。本書そのものもセマンティック記法だけで書かれており、`pptmdmerge crop_to_pdf` で PDF（Typst エンジン）にしています。

セマンティック記法とは、「ここは注意書き」「ここはファイル名」のように**意図**だけを書く記法です。LaTeX や HTML の命令（リテラル）は原稿に書かず、PDF / HTML / GFM（素の Markdown）の各出力形式へは、最後の変換段（lowering）がそれぞれの書き方に置き換えます。

::: {.note}
本書は PDF（Typst）出力での見た目を解説します。同じ原稿を HTML や GFM（puremd）に出したときの変換結果は、第 8 章の一覧表にまとめています。
:::

## 記法の 4 つのカテゴリ

| カテゴリ | 書き方 | 用途 | 章 |
|---|---|---|---|
| ブロック | `::: {.クラス}` … `:::` | 囲み・字下げ・中央寄せなど、複数行のまとまり | 第 2・3 章 |
| インライン | `[語句]{.クラス}` | 用語・パス・キー入力など、行中の語句 | 第 4 章 |
| リーフ | `{{名前}}` / `{{名前:引数}}` | 行空け・改ページ・見出し内改行 | 第 5・6 章 |
| escape hatch | ```` ```{=typst} ```` など | どうしても生コードが要るときの抜け道 | 第 7 章 |

定義の正典は `src/md_merge/semantics.yaml` です。書けるクラス名はここに定義されたものだけで、それ以外のクラスを書いても PDF では中身が素の文章として残るだけです。

## 本書の読み方

各用例は次の 2 段で示します。

- **書き方** … 原稿 MD に書くテキスト（コードブロック）
- **表示結果** … その直後に、同じテキストを実際に PDF にしたもの

::: {.warning}
コードブロックの中に書いた変数マーカー・ID マーカー・番号参照マーカーや、行頭の include 指示は、コードブロックの中でも merge / render が展開・置換します（コードフェンスを認識しないため）。本書の用例にこれらを含めていないのはそのためです。セマンティック記法（`:::` / `[…]{.…}` / リーフ記法）はコードブロックの中では変換されません。
:::

## ビルド方法

本書は `examples/semantic_notation_guide/` にあり、次のコマンドでビルドできます。pptx は使わず、MD 原稿だけを結合します（`typst` 0.15.1 と pandoc 3.9 が PATH 上に必要）。

```bash
cd examples/semantic_notation_guide
pptmdmerge crop_to_pdf semantic_notation_recipe.yaml --force
```

出力は `build/semantic_notation_guide.pdf` と、同じ名前の `.typ` です。
